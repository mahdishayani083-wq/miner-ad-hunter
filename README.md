# شکارچی آگهی ماینر

داشبورد مستقل برای رصد و بررسی آگهی‌های فروش ماینر؛ جدا از پروژه ماشین‌حساب ماینینگ.

## نسخه فعلی: ۰.۱
- رابط فارسی و راست‌چین، سازگار با موبایل
- فیلتر مدل‌های M30S، M30S+ و M30S++
- فیلتر وضعیت و واحد پول
- جستجو و آمار خلاصه

**توجه:** داده‌های فعلی نمونه و ساختگی‌اند. هنوز اتصال زنده به دیوار یا منبع دیگری پیاده‌سازی نشده است. واحدهای تومان و ریال جداگانه نگه داشته می‌شوند.

## اجرا
فایل `index.html` را در مرورگر باز کنید. راهنمای انتشار در [راهنمای مرحله اول](docs/PHASE_1_FA.md) است.

## نقشه راه
1. داشبورد اولیه
2. دریافت داده از منابع مجاز
3. تشخیص هوشمند مدل و استخراج ویژگی‌ها
4. حذف آگهی تکراری و تاریخچه قیمت
5. آماده‌سازی پیام استعلام با تأیید کاربر
6. اعلان تلگرام و گزارش‌ها
